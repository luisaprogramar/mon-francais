# Mon Français — plano de estudos de 90 dias

Um site estático para organizar um plano intensivo de francês. Feito com HTML, CSS e JavaScript puro, sem dependências ou build.

## Como usar localmente
1. Baixe ou clone este repositório.
2. Abra `index.html` no navegador.
3. Marque as tarefas conforme concluir. O progresso fica salvo no `localStorage` do navegador.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` e este `README.md` para a raiz do repositório.
3. Vá a **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação e abra o endereço indicado pelo GitHub Pages.

## O que já está implementado
- Navegação por Meu dia, Cronograma, Semanas, Conteúdos, Vocabulário, Materiais, Avaliações, Progresso e Configurações.
- Plano de 90 dias, com cinco tarefas por dia e rotina semanal.
- Checklist por dia e cálculo de progresso.
- Calendário com dias concluídos.
- Cadastro de recursos e links externos.
- Anotações nos checkpoints.
- Data de início configurável.
- Exportação dos dados em JSON e opção de zerar progresso.
- Layout responsivo para celular e computador.

## Observações
- O projeto não possui backend ou conta de usuário. Os dados ficam no navegador em que o site é usado. Use a exportação JSON para guardar um backup.
- Os canais e sites na biblioteca são pontos de partida. Os links para vídeos específicos devem ser conferidos e cadastrados manualmente.
- O cronograma é uma estrutura de organização, não uma garantia de proficiência B1 em 90 dias. Ajuste a carga e as avaliações conforme seu progresso.
